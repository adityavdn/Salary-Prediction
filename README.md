# 💰 Salary Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![ML](https://img.shields.io/badge/ML-Regression-green.svg)

## 📖 Overview

Regression model to predict employee salaries based on experience, education, job role, location, and company size. Provides insights into salary determinants and compensation trends.

## 🎯 Features

- Multiple regression algorithms comparison
- Feature importance analysis
- Salary range predictions
- Compensation factor analysis

## 🛠️ Tech Stack

- Scikit-learn (Linear, Ridge, Lasso, Random Forest)
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Salary-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Model Performance

- R² Score: 0.85+
- RMSE optimization
- Cross-validation scores
